**Interfaz del LLM.**

```python
# src/agents/llm_port.py
class ChatMessage(BaseModel):
    role: Literal["user", "assistant"]
    text: str

class LLMPort(Protocol):
    def generate(self, system: str, messages: list[ChatMessage]) -> str: ...
```

```python
# src/agents/ollama_adapter.py
class OllamaAdapter:
    def __init__(self, model: str, base_url: str) -> None: ...
    def generate(self, system: str, messages: list[ChatMessage]) -> str: ...
```
- `OllamaAdapter` implementa `LLMPort` y devuelve solo el texto de la respuesta del modelo.
- No lee `.env`. `model` y `base_url` llegan por parámetro.
- En S05 no hay reintento ni texto de respaldo: si Ollama no responde, la excepción sube al llamador. No se convierte en `revision_humana`.

**Prompt.**

```python
# src/agents/prompt.py
class PromptPieces(BaseModel):
    identity: str
    tone: str
    limits: str
    tools: str
    memory: str

def load_prompt_pieces(path: Path) -> PromptPieces: ...
def compose_system_prompt(pieces: PromptPieces) -> str: ...
```
- `load_prompt_pieces` lee las cinco secciones. El valor de cada campo es el contenido de su sección, sin el encabezado y sin espacios sobrantes al inicio y al final.
- Si falta una sección, lanza `ValueError`. El mensaje contiene el nombre de la sección (por ejemplo `Memoria`). Si faltan varias, nombra la primera que falta en el orden de la tabla de arriba.
- `compose_system_prompt` devuelve un solo texto con las cinco piezas en el orden `identity`, `tone`, `limits`, `tools`, `memory`. Cada pieza aparece en el texto sin cambios.

**Verificación.**

```python
# src/agents/verification.py
class VerificationResult(BaseModel):
    ok: bool
    reasons: list[str]

def verify_response(text: str) -> VerificationResult: ...
```

Códigos exactos de `reasons`, en este orden si aplican: `"empty"`, `"too_many_lines"`, `"too_many_questions"`, `"invented_price"`.
- `empty`: `text.strip() == ""`. Es decir, el texto solo tiene espacios, tabulaciones o saltos de línea. Si aplica, es el **único** motivo.
- `too_many_lines`: más de 3 líneas que no estén vacías. Una línea está vacía si, sin espacios en blanco, no tiene caracteres. Las líneas vacías no cuentan.
- `too_many_questions`: más de 1 carácter `?` (signo de cierre, U+003F) en todo el texto. El `¿` no cuenta.
- `invented_price`: el texto contiene alguna de estas formas (la primera letra de `S/` y `PEN` es literal, sin distinguir mayúsculas en `soles`):
  - (a) `S/` seguido de punto opcional, espacios opcionales y un dígito: `S/25`, `S/. 25`, `S/ 25`.
  - (b) `$` seguido de espacios opcionales y un dígito: `$25`.
  - (c) la palabra `PEN` en mayúsculas seguida de espacios opcionales y un dígito: `PEN 25`.
  - (d) un número, con parte decimal opcional con punto o coma, seguido de uno o más espacios y de `soles` o `nuevos soles`: `120 soles`, `24,50 soles`, `120 nuevos soles`.
- `ok` es `True` solo si `reasons` está vacío.

**Servicio y respuesta.**

```python
# src/agents/conversation_service.py
class ConversationResult(BaseModel):
    status: Literal["respondido", "revision_humana"]
    text: str | None
    reasons: list[str]

class ConversationService:
    def __init__(self, llm: LLMPort, system: str) -> None: ...
    def respond(self, messages: list[ChatMessage]) -> ConversationResult: ...
```
- `respond` llama a `llm.generate(system, messages)` exactamente una vez por turno.
- Si la verificación da `ok`: `status="respondido"`, `text` es la respuesta del modelo sin cambios, `reasons=[]`.
- Si no: `status="revision_humana"`, `text=None`, `reasons` son los de la verificación. En S05 no hay reintento.
- `"respondido"` es el mismo valor que usa S05 D1 en el estado del grafo. El valor nuevo es `"revision_humana"`.

```python
# src/agents/respond_node.py
def make_respond_node(service: ConversationService) -> Callable[[Mapping[str, Any]], dict[str, Any]]: ...
```
- El nodo lee `state["messages"]`: convierte `HumanMessage` a `user` y `AIMessage` a `assistant`, e ignora otros tipos. Luego llama a `service.respond(...)`.
- Si el resultado es `respondido`, devuelve `{"messages": [AIMessage(content=text)], "status": "respondido"}`.
- Si el resultado es `revision_humana`, devuelve `{"status": "revision_humana"}` y no agrega mensajes.
- El nodo **no** devuelve `intent`, `phone` ni `tenant`: esas claves quedan como llegaron.
- La llamada al LLM vive en el servicio, no en el nodo (`AGENTS.md`: nodos de grafo sin efectos secundarios).

**Grafo de conversación (archivo nuevo).**

```python
# src/agents/conversation_graph.py
from langgraph.graph.state import CompiledStateGraph

def build_conversation_graph(service: ConversationService) -> CompiledStateGraph: ...
```
