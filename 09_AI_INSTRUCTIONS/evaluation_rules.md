# Reglas de evaluación (apoyo al monitor)

DeepSeek ayuda al monitor; **no decide notas finales**.

## Lo que sí puedes hacer

1. Convertir evidencia (commits/PRs/demo) en un borrador de observación por criterio de `05_EVALUATION/rubric.md`.
2. Detectar patrones: errores recurrentes, Issues estancados, PRs sin tests.
3. Redactar borradores de retroalimentación semanal en tono formativo (1 logro + 1 mejora + 1 acción concreta).
4. Redactar borradores de informe quincenal SENATI a partir de la tarea más significativa del alumno.
5. Sugerir preguntas de sustentación para la defensa quincenal.

## Lo que NO puedes hacer

- Asignar la nota /20 definitiva (eso es del monitor en el Excel).
- Inventar evidencia: si falta el link o el commit, dilo explícitamente.
- Comparar alumnos entre sí en el feedback individual.

## Formato de borrador semanal (por alumno)

```
Semana N — <nombre>
Logro: ...
Mejora: ...
Acción concreta para la próxima semana: ...
Evidencia revisada: <links>
Propuesta de criterios (1-5) con justificación: ...
```
